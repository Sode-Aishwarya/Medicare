# Medicare
### Clinic Management System:
A web-based Clinic Management System developed using PHP, HTML, CSS, and MySQL to manage patient information, doctor details, appointments, and medical records. The system helps clinics maintain organized records and streamline daily operations.

#### Project Overview:
This project provides a simple platform for managing clinic operations digitally. It allows staff to handle patient registrations, schedule appointments, and maintain medical records efficiently.The system reduces manual paperwork and improves data management within a clinic environment.

#### Technologies Used:
Frontend: HTML, CSS
Backend: PHP
Database: MySQL
Server: Apache (via XAMPP)

#### Features:
Staff login authentication
Manage patient records
Manage doctor information
Schedule and track appointments
Maintain medical records
Manage diagnostic tests

#### Database Tables:
The system uses the following database tables:
patients – Stores patient details
doctor – Stores doctor information
appointment – Stores appointment schedules
staff – Staff login and details
tests – Diagnostic tests information
medical_record – Patient medical history
clinic – Clinic details

#### Installation Steps:

S1.Install XAMPP.
S2.Start Apache and MySQL services.
S3.Copy the project folder into:
xampp/htdocs/
S4.Import the database file (.sql) using phpMyAdmin.
S5.Open the browser and run:
http://localhost/project-folder/login.php
